# Hero video

Place the client's hero footage here:

- `hero-printing.mp4` — desktop/landscape (1920×1080, H.264, ~6–10 MB, 15–25 s loop, no audio)
- `hero-printing-mobile.mp4` — optional portrait/lighter version for phones (1080×1350 or 720p)

Shot list: extreme close-up of the nozzle → filament extrusion → sculpture forming
layer by layer → camera moving around the printer → finished sculpture reveal.
No text in the video — headings are rendered by the page.

Until `hero-printing.mp4` exists, the homepage plays an animated canvas print
sequence over the poster image (`public/assets/images/hero/hero-poster.svg`).
